# NoahOS
A simple operating system run on a TI-83 Plus calculator. Not an actual OS, but runs in the PRGM files of the system. This lightweight operating system is the foundation for many applications, formula solvers, and games for your TI-83 Plus calculator.

# Step 1
Download the TI Connect app from the official TI website: https://education.ti.com/en/software/details/en/B59F6C83468C4574ABFEE93D2BC3F807/swticonnectsoftware
Then download all the .prgm files from the repository.
Don't download the OS.base files yet; we will need them later.
# Step 2
Send the .prgm files to the calculator through TI Connect.
Once complete, download the OS.base and OS image files from the repository.
Then send over the OS files to the calculator through TI Connect.
# Step 3
Turn on the calculator, press the PRGM key, and scroll down until you see OS.
Click ENTER and wait for OS to set up and boot.
The default password is 1234; you can change this later in the SECURITY program files in the EDIT menu of OS.
Once in the OS, you can choose from a variety of games and formula solvers via the arrow keys. Highlight the application you would like to run, and press ENTER.
# Step 4
In order to exit most apps, press the ON button on the bottom left of your calculator. You will see ERROR: BREAK.
This is normal and means the code has stopped running.
Press CLEAR or select QUIT from the options to exit.
If you would like to exit NoahOS and return to the normal TI calculator software, use the arrow keys in the main NoahOS menu until you see QUIT.
Then press ENTER, and then CLEAR to exit.
