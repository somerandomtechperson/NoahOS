# NoahOS
A simple operating system run on a Ti-83 Plus calculator. Not an actual OS, but run in the PRGM files of the system.

Download the TI connect app from the official TI website: https://education.ti.com/en/software/details/en/B59F6C83468C4574ABFEE93D2BC3F807/swticonnectsoftware
Then download the OS files from the respitory.
Send files to calculator thru TI Connect.
Turn on calculator, press the PRGM key, and scroll down until you see OS. Click ENTER and wait for OS to boot.
The defualt password is 1234, you can change this later in the SECURITY program files in the PRGM menu.
Once in the OS, you can choose from a variety of games and formula solvers via the arrow keys. Highlight the application you would like to run, and press ENTER.
In order to exit from most apps, press the ON button on the bottom left of your calculator. You will see ERROR: BREAK. This is normal and means that the code has stopped running, press CLEAR or select QUIT from the options.
If you would like to exit NoahOS and return to the normal TI calculator software, use the arrow keys in the main NoahOS menu until you see QUIT, then press ENTER, and then CLEAR to exit.
