# NoahOS Security Policy

## Reporting a Vulnerability

If you discover a vulnerability in NoahOS, we encourage you to report it promptly. Here's how to do so:

1. **Reporting Channel**: Please submit your findings via our dedicated discussion on GitHub. Make sure to include detailed information about the vulnerability.
  
2. **Response Time**: We aim to acknowledge vulnerability reports within 48 hours. After that, we will investigate the issue and keep you updated on our progress.

3. **Acceptance Process**: If the vulnerability is confirmed, we will prioritize fixing it and release a patch in a future update. You will be notified once the fix is available.

4. **Declined Reports**: If a report is declined, we will provide feedback explaining why the issue doesn’t warrant a security update.

### Confidentiality
We value the importance of security and confidentiality. All reports will be handled discreetly, and your identity will remain confidential unless you choose to disclose it. 

Thank you for helping to keep NoahOS secure!
